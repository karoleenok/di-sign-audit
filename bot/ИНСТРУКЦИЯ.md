# Бот Di Sign University — как запустить

Бот: **@di_sign_university_bot**. Сейчас — тестовый запуск на Cloudflare (бесплатно).
Пока бот на Cloudflare, пользуемся им **только мы с Дианой и пара знакомых**. Публичную ссылку из теста включаем после переезда на российский сервер.

Токен бота **никому не присылаем и не вставляем в чат** — только в настройки Cloudflare (шаг 4).

---

## Что понадобится
- Токен бота из @BotFather (сообщение после `/newbot`, вида `1234567890:AA…`)
- Ваш Telegram-id: напишите @userinfobot, он пришлёт число
- Файл `dist/worker.js` из этой папки

## Шаг 1. База данных
1. Зайдите на dash.cloudflare.com.
2. Слева: **Storage & Databases → D1 SQL Database**.
3. **Create** → имя `di-sign-bot` → **Create**.

## Шаг 2. Сам бот (Worker)
1. Слева: **Workers & Pages** → **Create** → **Create Worker** (Hello World).
2. Имя: `di-sign-bot` → **Deploy**.
3. Нажмите **Edit code**. Удалите весь код в окне, вставьте всё содержимое файла `dist/worker.js` → **Deploy**.

## Шаг 3. Подключить базу к боту
1. Откройте воркер `di-sign-bot` → вкладка **Settings** → **Bindings** → **Add**.
2. Выберите **D1 database**.
3. Variable name: `DB` (заглавными), база: `di-sign-bot` → **Add/Save**.

## Шаг 4. Секреты и настройки
Там же **Settings → Variables and Secrets → Add**. Для каждой строки:

| Имя | Тип | Что вписать |
|---|---|---|
| `BOT_TOKEN` | **Secret** | токен из @BotFather |
| `SETUP_KEY` | **Secret** | придумайте пароль латиницей и цифрами, например `taksa2026setup` |
| `WEBHOOK_SECRET` | **Secret** | ещё один придуманный пароль латиницей и цифрами |
| `ADMIN_IDS` | Text | ваш Telegram-id (если сразу и Диана — через запятую) |
| `POLICY_URL` | Text | ссылка на политику обработки данных (можно позже) |
| `CONSENT_URL` | Text | ссылка на текст согласия (можно позже) |
| `OFFER_URL` | Text | ссылка на оферту (можно позже) |
| `TEST_URL` | Text | ссылка на тест для кнопки «Пройти тест»: `https://di-sign-bot.<имя>.workers.dev/test` |
| `OWNER_INFO` | Text | например: «Самозанятая Иванова К. И., ИНН …» (можно позже) |

Нажмите **Deploy / Save**.

## Шаг 5. Расписание (раз в минуту)
**Settings → Trigger Events (Triggers) → Add → Cron Trigger** → выберите «каждую минуту» или впишите `* * * * *` → **Add/Save**.

## Шаг 6. Включить
1. На странице воркера скопируйте его адрес, вида `https://di-sign-bot.ВАШЕ-ИМЯ.workers.dev`.
2. Откройте в браузере: `https://di-sign-bot.ВАШЕ-ИМЯ.workers.dev/setup?key=ВАШ_SETUP_KEY`
3. Должно появиться «Готово 🐾».

## Шаг 7. Проверить
1. В Telegram откройте бота → `/start` (пройдёте путь ученика: согласия, уровень, кнопка теста).
2. Отправьте `/check` — всё должно быть с ✅.
3. Отправьте `/new` и сделайте первый пост с премиум-эмодзи. На предпросмотре сразу видно, прошли ли эмодзи.

## Как пользоваться (для вас и Дианы)

| Команда | Что делает |
|---|---|
| `/new` | новый пост: текст, фото, альбом до 10, файлы, кнопки |
| `/posts` | все посты: показать себе, пауза, правка, отправить сейчас, архив |
| `/stats` | сколько людей, уровни, сколько прошли тест, откуда пришли, нажатия |
| `/admins` | кто админ; `/addadmin 123` — добавить, `/deladmin 123` — убрать |
| `/check` | проверка: связь с Telegram, база, расписание |
| `/cancel` | отменить, если запутались |
| `/admin` | панель: лента по дням с перетаскиванием, даты, подарки, все тексты бота |
| `/texts` | поменять любое сообщение бота прямо в Telegram (с премиум-эмодзи) |
| `/help` | памятка прямо в боте: как устроен, как делать посты, что выкладывать, примеры |

**Добавить Диану:** Диана пишет боту `/id` → присылает вам число → вы отправляете `/addadmin ЧИСЛО`.

**Три вида постов:**
- **через N дней после входа** — лента: каждый получает в свой день, в выбранное время по Москве (день 0 — сразу);
- **в дату и время** — один раз всем подходящим, кто уже в боте (эфиры, анонсы);
- **подарок после теста** — уходит сразу после теста: всем, начинающим или продолжающим.

**Кому:** всем / начинающим / продолжающим. Отдельных постов под слабые места из теста нет.

**Кнопки:** по строке на ряд: `Текст кнопки | https://ссылка`. Несколько в ряд — через `;`. Бот считает нажатия.

**Альбом:** отправьте картинки одним альбомом, подпись станет текстом. Кнопки к альбому Telegram прикрепить не даёт — бот отправит их следующим сообщением сразу под альбомом.

**Ссылка из теста:** `https://t.me/di_sign_university_bot?start=audit_P_start` — тест уже формирует её сам (отметка «прошёл тест» и уровень). Ссылка на бота в тесте уже стоит.

## Переезд на российский сервер (потом)
1. Выгрузка всех данных одной ссылкой: `https://…workers.dev/export?key=ВАШ_SETUP_KEY` — скачается файл `bot-backup-….json`. Храните его у себя, в чат не присылайте.
2. На новом сервере: та же папка бота, команда `node scripts/import.js bot-backup-….json`, запуск `node src/node-server.js`, те же настройки (секреты), плюс `PUBLIC_URL`.
3. Открыть `https://новый-адрес/setup?key=…` — Telegram переключится на новый сервер. Отправленное повторно не уйдёт.
4. Если Telegram недоступен с российского сервера: включаем «мост» (`dist/relay.js` — отдельный маленький воркер на Cloudflare, ничего не хранит) и режим `MODE=polling`.

Этот шаг проведу пошагово, когда выберем хостинг.


## Вход в бота (с 31.10.2026)
1. Аудит передаёт выбор: `…?start=audit_<зона>_<уровень>_course` (мини-курс) или `_month` (материалы).
2. Бот: приветствие → согласие на данные (политика, согласие) → согласие на рассылку → уровень (если не из аудита) → имя → контакт (Telegram / телефон кнопкой / почта) → отзыв о прототипе кабинета по желанию (за него — посты «💬 Бонус за отзыв»; отзыв приходит админам в бот) → мини-курс или материалы (если не выбрал в аудите) → подарок → пост-расписание по треку → лента.
3. У каждого поста есть «трек»: всем / мини-курс / материалы.
4. Все тексты шагов меняются в панели (/admin → «Тексты») или в боте (/texts). Ссылки на документы — /admin → «Сценарий» → «Документы».

## Аудит-тест
Файл теста лежит в репозитории GitHub `karoleenok/di-sign-audit` (index.html). Бот показывает его по адресу `…workers.dev/test`. Поменять тест = заменить index.html в репозитории, через 5 минут обновится.


### Порядок шагов входа
Панель → Сценарий → «Вход в бот»: шаги можно перетаскивать за ⋮⋮ (или кнопками ▲▼), а необязательные — выключать (имя, контакт, отзыв, мини-курс/материалы, тест). Согласие на данные всегда первое, согласие на рассылку и уровень можно двигать, но нельзя выключить. Тексты, паузы и кнопки-ссылки каждого шага меняются по нажатию на шаг.

### Переезд на свой сервер (Россия)
Сервер: Ubuntu 24.04, 1 ядро, 1–2 ГБ. В веб-консоли сервера одной строкой:
`curl -fsSL https://raw.githubusercontent.com/karoleenok/di-sign-audit/main/bot/deploy/install.sh | bash`
Скрипт ставит Node 22 и HTTPS-адрес, спрашивает токен бота и ключи (они остаются только на сервере), при желании переносит базу со старого бота и после «да» переключает Telegram на сервер. Обновление: `bash /opt/di-sign-bot/bot/deploy/update.sh`. Если Telegram с сервера недоступен, скрипт попросит адрес «моста» (`dist/relay.js` на Cloudflare) и включит режим polling.
