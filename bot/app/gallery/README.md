# Галерея примеров на экране результата теста

**Проще всего из аппки:** админ открывает аппку из бота, на главном экране карточка «Ты админ» → «Примеры работ». Там выбор стиля, загрузка картинки, автор, название, год, ссылка, порядок и удаление. Данные лежат в базе, картинки на диске сервера рядом с базой (папка `gallery`), автообновление их не трогает. Если в базе пусто, берётся этот `data.json`.

Как добавить работу через репозиторий: положить картинку в эту папку и дописать строку в `data.json`. Правка файлов в `bot/app/` не нужна, автообновление подхватит всё за ~3 минуты. Если стиль не указан в `data.json` или список пуст, блок на экране результата не показывается.

Ключи стилей: `br` брутализм, `sw` швейцарский, `rf` ретрофутуризм, `ad` арт-деко, `mm` мемфис, `nw` новая волна, `bh` баухаус, `jp` японский минимализм.

```json
{
  "br": [
    { "a": "Pierre Jeanneau", "t": "«Super cellule 3»", "y": "2023", "u": "https://…", "i": "br-01.webp" }
  ]
}
```

- `a` автор, обязательно. Без него работа не показывается.
- `t` название, `y` год: по желанию, показываются только если заполнены.
- `u` ссылка на первоисточник, только `https://`. Если пусто, кнопка «Открыть источник» скрыта.
- `i` имя файла картинки в этой папке: латиница, цифры, дефис, расширение `.webp` или `.jpg`. Без картинки показывается цветная плитка с номером.

Картинки: соотношение 4:5 (например, 800×1000), WebP, до ~100 КБ. Показываются обрезкой по центру в ленте и целиком в шторке.
Порядок работ в списке равен порядку в ленте. Лучше 4–5 работ на стиль.
